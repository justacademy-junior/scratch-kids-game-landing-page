# Scratch for Kids: Build a Simple Game in 30 Minutes

A playful, responsive landing page that shows parents how a child can build a Catch the Apple game in Scratch in about 30 minutes. It includes a playable mini game, a four stage build plan, skill cards, an FAQ and clickable next step links.

## What is inside

- A sticky header and a fun sticker style footer
- A playable Catch the Apple mini game (mouse, touch or arrow keys)
- A 30 minute game plan in four stages
- Cards showing what kids learn from block based coding
- An FAQ built with native `details` elements
- Fully responsive layout and reduced motion support

## Quick start

1. Download or clone this repository.
2. Open `index.html` in any browser. No build step or dependencies are needed.

## Deploy on GitHub Pages

1. Push `index.html` and `README.md` to the `main` branch.
2. Go to **Settings > Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and the `/ (root)` folder, then save.
4. Your site will be live at `https://<your-username>.github.io/<repository-name>/`.
